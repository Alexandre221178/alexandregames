時間はテンプスの前で止まる。そして、敵にとっても同じことが起こる。永遠の道に属するサポートヒーローであるテンプスは、戦闘そのもののルールをねじ曲げる。敵のスキルタイマーを凍結し、能力値を削り、もっとも危険なアタッカーを隔離し、味方の最大HPを驚異的なレベルまで引き上げる。過去と未来のすべての秘密を知る者にとって、戦場での一手一手は計算し尽くされた必然のプレイになる。

この完全ガイドでは、ヒーローウォーズ アライアンスにおけるテンプスのすべてを解説する。スキル、タリスマンの選び方、スキンの優先度、最適編成、そしてレジェンダリー・レリックによって優秀なコントローラーから止められない存在へと変貌する仕組みまで、必要な情報をすべて網羅している。これから初めて育成する人にも、新しいレリックスキルで強化を進める人にも、このガイドは戦略を研ぎ澄まし、テンプスを編成の中心にしてくれる。

ヒーローウォーズ アライアンスのテンプスとは？

テンプスは永遠の道に属する中衛のサポートヒーローで、時間の力を操って戦場全体を支配する。彼のキットはクラウドコントロール、デバフ、味方強化を組み合わせた構成になっており、すべての味方を底上げしながら、敵のあらゆる作戦を分解していく存在だ。レジェンダリー・レリックを解放すると、新たな攻撃性能と対コントロールの防御機構が加わり、十分に投資したときの完成度は非常に高い。

  • メインクラス: サポート
  • 配置: 中衛
  • メインステータス: 知力
  • 所属派閥: 永遠の道
  • 装備ランク: 16
  • ソウルストーン入手方法: 特別イベント
  • シナジー: アイリス、コルヴァス、フォボス、カイラ、アイダン
  • ハイドラTier: 未確定

クロノスタシスで敵のスキルクールダウンを凍結できる独自能力により、テンプスは対人戦で特に厄介な妨害役のひとりになっている。さらに、敵の物理攻撃力と最大HPを削るウィザリング、味方を加速しつつ敵を減速させ、味方の最大HPまで引き上げるタイムパラドックスが組み合わさることで、敵チームを弱体化しながら自軍を同時に強化できる。

カイラとアイダンとの相性は特に優秀だ。テンプスはタイムパラドックスによって味方の最大HPを増加させるが、これはアイダンのフェニックス・リチュアルを直接強化することにつながる。その結果、HP増加、チーム蘇生、継続圧力が連鎖的に噛み合い、相手にとって非常に崩しにくい展開を作り出せる。

テンプスの長所と短所 - ヒーローウォーズ アライアンス

✅ 長所

  • クロノスタシスはすべての敵を同時に停止させ、スキルのクールダウンまで凍結する。ゲーム内でも最上級クラスのCCスキルだ。
  • ウィザリングは敵の物理攻撃力と最大HPを大幅に下げ、前衛ヒーローを機能不全に追い込む。
  • タイムパラドックスは味方の最大HPと速度を強化しつつ、範囲内のすべての敵を減速させる。
  • 永遠の道、アイリス、コルヴァス、フォボス、さらにカイラ＋アイダン編成と抜群の相性を持つ。
  • レジェンダリー・レリックで魔法貫通オーラ（クロノフィールド）と自動CC反射（タイムリバウンド）を獲得し、投資が進むほど価値が大きく伸びる。

❌ 短所

  • 中衛配置のため、強固な前衛がいないと範囲ダメージや瞬間火力に巻き込まれやすい。
  • ダメージ自体は中程度で、主役はあくまでコントローラー兼サポートであり、メインアタッカーではない。
  • 最大性能を引き出すにはレジェンダリー・レリックへの投資が必要で、育成コストが重い。
  • コントロール連鎖やHP依存シナジーを最大化するには、編成の組み方にかなり依存する。

テンプスのレジェンダリー・レリックスキル育成優先度 - ヒーローウォーズ アライアンス

あらゆる時間軸を支配しよう。テンプスの各スキル、正確な計算式、そして戦場を制圧するために優先すべき強化順を確認していく。

レリックはヒーローに新しい能力を与え、既存スキルも強化する。スキル強化だけでなく、各ヒーローの2つのサブステータスも上昇する。どのステータスが強化されるかは、そのヒーローのスキル計算式がどの能力値を参照しているかで決まる。

1 - クロノスタシス

ゲーム内説明: 敵ヒーロー全員の時間を停止する。2.5秒の間、対象はスキル使用、移動、回避ができず、アーマーと魔法防御が27,241.65 (13% Mag.atk. + 1800)低下する。このスキルの持続中、対象になった敵のすべてのスキルクールダウンは凍結される。このスキルは敵に付与されているすべての呪いとデバフの持続時間を延長する。

スキル解説: クロノスタシスはテンプスのアルティメットであり、彼のキット全体の中心だ。戦場にいる敵全員が同時に止まるイメージをしてほしい。2.5秒のあいだ、敵は動けず、スキルを使えず、回避もできない。その間、こちらのチームは一方的に攻撃できる。しかも停止した敵はアーマーと魔法防御まで下がるため、この短い時間の火力効率が一気に跳ね上がる。さらに重要なのが、敵にすでに入っているすべてのデバフと呪いの持続時間まで延ばす点だ。たとえばアイリスやフォボスが呪いを入れていれば、その影響をさらに長く押しつけられる。戦闘全体が、完璧に演出された処刑のように進んでいくスキルだ。

永続のタリスマン装備時の計算式

  • アーマーと魔法防御の低下量: 27,241.65 (13% Mag.atk. + 1800)

時間厳守のタリスマン装備時の計算式

  • アーマーと魔法防御の低下量: 26,461.65 (13% Mag.atk. + 1800)

スキルアニメーション情報

  • アーマーと魔法防御の低下量: (13% Mag.atk. + 1800)
  • キーワード: デバフ、コントロール
  • アニメーション遅延: 1.0秒
  • 持続時間: 2.5秒

育成優先度: 最優先 - リソースがあるならまず最初に上げるべきスキルがクロノスタシスだ。テンプスのキットの中で最強のコントロール性能を持ち、敵チーム全体を止めながらスキル回転まで封じる。この2.5秒は味方にとって完全な攻撃フリータイムになる。さらに、アーマーと魔法防御の低下によって魔法火力の味方全員が恩恵を受けるため、テンプスに投資したときの見返りがもっとも大きい強化になる。

2 - ウィザリング

ゲーム内説明: 自身の前方にいる遠距離の敵を6.0秒間弱体化する。弱体化された敵は物理攻撃力を24,370.5 (10% Mag.atk. + 4800)、最大HPを126,423 (60% Mag.atk. + 9000)失う。

スキル解説: ウィザリングは、敵の急所を同時に刺す二重デバフだ。物理攻撃力を下げることで前衛が受けるダメージを軽減し、さらに最大HPまで大きく削る。見かけ上600,000HPある敵でも、126,000を失えば実際の耐久は大きく落ちる。最大HP低下は、味方がすでに与えているダメージにも重なるため特に強力だ。このスキルは初回8秒後、その後は12秒ごとに発動し、テンプスの前方にいる遠距離の敵を広い範囲で巻き込む。戦闘中ずっと敵チームを弱らせ続ける、安定した継続圧力の要になる。

永続のタリスマン装備時の計算式

  • 物理攻撃力低下: 24,370.5 (10% Mag.atk. + 4800)
  • 最大HP低下: 126,423 (60% Mag.atk. + 9000)

時間厳守のタリスマン装備時の計算式

  • 物理攻撃力低下: 23,770.5 (10% Mag.atk. + 4800)
  • 最大HP低下: 122,823 (60% Mag.atk. + 9000)

スキルアニメーション情報

  • 物理攻撃力低下: (10% Mag.atk. + 4800)
  • 最大HP低下: (60% Mag.atk. + 9000)

  • 初回クールダウン: 8秒
  • クールダウン: 12秒
  • アニメーション遅延: 1.0秒
  • 持続時間: 6.0秒
  • 範囲: 200
  • 射程: 3000

育成優先度: 高い - クロノスタシスの次に優先したいのがウィザリングだ。物理攻撃力低下と最大HP削りの組み合わせによって、敵を倒しきる難易度が大きく下がる。とくにクロノスタシスで作った無抵抗時間と組み合わさると、その価値はさらに高まる。魔法攻撃をしっかり伸ばした状態では最大HP低下だけで126,000を超え、500,000から900,000以上のHPを持つヒーローが並ぶゲームでは非常に大きな差になる。


2 - ウィザリング（強化スキル）レジェンダリー・レリック: レベル10

ゲーム内説明: さらに自身の前方にいるすべての敵にもデバフを付与するようになる。

スキル解説: この強化前のウィザリングは「遠距離の敵」だけを対象にしていた。つまり、テンプスから離れた位置にいる敵しか巻き込めなかったということだ。レリックレベル10になると、このスキルは前方にいるすべての敵へ拡張され、近距離の相手も対象に含まれる。これはかなり大きな戦術的強化で、前衛も中衛も物理攻撃力低下と最大HP低下から逃げられなくなる。密集編成や近接タンクを使う相手に対して、とくに価値が高い。

スキルアニメーション情報

  • 条件: レジェンダリー・レリック レベル10
  • キーワード: デバフ
  • 範囲拡張: これまでの遠距離限定ではなく、前方のすべての敵に適用

育成優先度: 高い - これは早い段階で取りたいレリック強化のひとつだ。前方全体を巻き込めるようになったことで、ウィザリングは状況依存のデバフから、安定した全体弱体化スキルへ変わる。敵が前衛と中衛に固まって戦うPvPでは特に効果が大きく、発動するたびに敵の主力層をまとめて削れるようになる。

3 - テンポラル・アノマリー

ゲーム内説明: もっともアーマー貫通が高い敵ヒーローを5.0秒間テンポラル・アノマリーへ送り込む。対象は25%減速し、50エネルギーを失い、さらに毎秒31,755.75 (15% Mag.atk. + 2400)の魔法ダメージを受ける。

スキル解説: テンポラル・アノマリーは、テンプスのピンポイント無力化ツールだ。敵全体を巻き込む代わりに、もっとも危険な物理アタッカーを正確に狙う。対象は「アーマー貫通がもっとも高い敵」であることが多く、つまりこちらのタンクを切り裂くために組まれた主力アタッカーということだ。捕まった相手は5秒間の時間ループに閉じ込められ、25%減速、毎秒50エネルギー減少、さらに継続的な魔法ダメージを受ける。ほとんどのヒーローにとって毎秒50エネルギー減少は致命的で、アルティメットを撃たせずに封じ込められる。初回クールダウンが1秒しかないため、戦闘開始直後から機能するのも大きい。

育成優先度: 高い - テンポラル・アノマリーは高優先度で育てたいスキルだ。戦闘開始直後に自動で相手の最大脅威を止める性能が非常に強い。5秒間で合計250ものエネルギーを削るため、多くのアタッカーはアルティメットを撃つ前に機能停止する。タンク視点で見ると、このスキルを育てるだけで敵の最大火力から受ける圧力が目に見えて下がる。

4 - タイムパラドックス

ゲーム内説明: 4.0秒間、アリーナ中央に巨大な時計を召喚する。時計の範囲内にいる敵は減速し、味方は10%加速する。さらに、影響を受けた味方の最大HPは146,593.5 (70% Mag.atk. + 9600)増加する。

スキル解説: タイムパラドックスは、両チームに同時に影響を与える戦場操作スキルだ。巨大な時計が戦場中央に現れ、味方は移動と攻撃が速くなり、敵は逆に鈍くなる。しかし本当に重要なのは、味方全体に入る非常に大きな最大HP上昇である。数値は146,593.5 (70% Mag.atk. + 9600)にも達する。この点がアイダンとの核になるシナジーで、アイダンのフェニックス・リチュアルは味方の最大HPを参照して強化されるため、タイムパラドックスでHPを増やすほど燃焼ダメージと支援効率が上がる。カイラと組み合わせれば蘇生ループもさらに安定する。発動のたびに味方は硬く速くなり、敵は鈍く脆くなる。

永続のタリスマン装備時の計算式

  • 味方の最大HP増加: 146,593.5 (70% Mag.atk. + 9600)
  • 味方加速 / 敵減速: 10%

時間厳守のタリスマン装備時の計算式

  • 味方の最大HP増加: 142,393.5 (70% Mag.atk. + 9600)
  • 味方加速 / 敵減速: 10%

スキルアニメーション情報

  • 味方の最大HP増加: (70% Mag.atk. + 9600)
  • キーワード: バフ
  • クールダウン: 16秒
  • アニメーション遅延: 1.0秒
  • 持続時間: 4.0秒
  • 範囲: 270
  • 射程: 3000
  • 味方加速 / 敵減速: 10%

育成優先度: 高い - タイムパラドックスはテンプスのサポート性能を支える主軸だ。最大HP上昇は魔法攻撃に大きく依存し、フル育成に近づくほど1回の発動で146,000以上もの耐久を味方に与える。アイダンを使うならさらに重要度が増し、増えた最大HPがそのままフェニックス・リチュアルの火力と支援力につながる。これは単なる便利スキルではなく、テンプスを本物のサポートにしている要の能力だ。


4 - タイムパラドックス（強化スキル）レジェンダリー・レリック: レベル20

ゲーム内説明: このスキル範囲内にいるすべての敵は、1秒ごとに魔法ダメージも受けるようになる。魔法ダメージ: 84,282 (40% Mag.atk. + 6000)。

  • 付与されるクロノスタシスの持続時間: 2.5秒
