オーヤはヒーローウォーズ アライアンスにおいて、最も危険な対シールド戦士の1人です。ネイチャー派閥のフロントライン・ストレングスヒーローとして、保護されている敵を大きなダメージで懲罰し、クリティカルヒット相乗効果、そしてレジェンダリーアーティファクト強化により、シールドに頼るチームを大幅に弱体化させます。

このガイドでは、オーヤの基本キットとレジェンダリースキルの仕組み、各タリスマンの使い分け、彼女の圧力を最大化する同盟者、そしてシールドブレーカー、プレデターバイト、ハントレスフューリーといったスキルがいかに彼女をPvPの脅威へと変えるのかを学べます。

オーヤとは?

オーヤはネイチャー派閥の強力なフロントライン戦士です。大きな物理攻撃スケーリング、シールド懲罰、クリティカルヒット相乗効果に基づいており、彼女のレジェンダリーアーティファクト強化は、バリアまたは防御タイミングに依存するチームに対してさらに圧力をかけます。

  • クラス: ウォーリアー
  • ポジション: フロントライン
  • メインステータス: ストレングス
  • 派閥: ネイチャー
  • ソウルストーンの入手方法: イベント、ヒロイックチェスト
  • ヒーロー全体ティアリスト: A
  • ハイドラティアリスト: B+
  • シナジー: ヤスミン、チャッバ、ジュー、イシュマエル、グウス

オーヤはヤスミン、ジュー、イシュマエルなどのクリティカルダメージディーラーと非常に相性が良く、高圧力の攻撃的チームを形成します。グウスとのシナジーは生存性と制御を強化し、チャッバはフロントラインサポートと注意引きを追加し、バックラインのアサシンが自由に動作するスペースを作成します。

シールドを無視する能力のおかげで、オーヤはタンキーなラインアップと保護者ヒーローに対して特に効果的です。魔法主体のチームに対しては効率が低いですが、物理構成に優れており、特にPvPバトルではシールド破壊と強力なフロントラインプレゼンスが大きな影響を与えます。

オーヤの長所と短所 - ヒーローウォーズ アライアンス

✅ 長所

  • ✔ 優れた対シールドヒーロー: シールドブレーカーは保護された敵に懲罰を与え、レジェンダリー強化版はシールドを持つすべての敵に圧力を拡散させます。
  • ✔ グウス、ヤスミン、ジュー、イシュマエルなどのクリティカル系同盟者との強力なシナジーで、バーストダメージと治癒トリガーの両方を改善します。
  • ✔ レジェンダリーアーティファクトキットは追加の制御とスケーリングを追加: オーバーウェルミングはエネルギーを焼き、プレデターバイトは反復的な圧力を追加し、ハントレスフューリーは与えられたシールドに報酬を与えます。
  • ✔ 柔軟なタリスマン選択で、生の物理攻撃バーストまたはより多くの生存性とクリティカル一貫性に傾くことができます。
  • ✔ 攻撃的なPvPチームで有用です。なぜなら彼女はタンク、低ヘルス目標、シールド依存のバックラインに同時に圧力をかけるからです。

❌ 短所

  • ✖ 彼女の全価値はマッチアップに依存します: 敵チームがシールドをほとんど使用しない場合、彼女の対シールド利点の一部が影響を失います。
  • ✖ 物理攻撃、生存性、クリティカルサポートに適切な投資が必要になってから、彼女の圧力が真に脅威となります。
  • ✖ チームシナジーとターゲットアクセスに依存するため、ポジションが悪いか間違ったラインアップは彼女の全体的な影響を減らします。
  • ✖ 魔法主体またはコントロール志向のチーム、その開始圧力を生き残り、フロントラインに報復する場合、より苦労する可能性があります。

オーヤ タリスマン ガイド ヒーローウォーズ アライアンス

オーヤには2つのタリスマンがありますが、バトルでは1つだけ装備できます。これはスキンとは異なります: スキンボーナスはアップグレード後は常にアクティブですが、タリスマンボーナスは現在装備されているタリスマンからのみ適用されます。オーヤのキースキルは物理攻撃からスケーリングし、シールド破壊メカニズムを持っているため、タリスマンの選択は彼女のダメージプロフィール、生存トリガー、キル圧力に直接影響します。

予言のタリスマン

メインステータススロット: ストレングス +2,000。ストレングスはオーヤのメインステータスなので、これは基本変換から+80,000 ヘルスと+2,000 物理攻撃を付与します。このタリスマンはリロール通じてクリティカル一貫性を改善しながらオーヤを安定化させることに焦点を当てています。

リロール スロット 1: クリティカルヒット確率 +2,200。リロール スロット 2: クリティカルヒット確率 +2,200。リロール スロット 3: クリティカルヒット確率 +2,200。これら3つのスロットを実際に1つの値として扱う: 合計リロールボーナス = クリティカルヒット確率 +6,600。

バトル推奨: ほとんどの場面では女戦士のタリスマンを装備しましょう。オーヤの主力ダメージスキルであるシールドブレーカー、ハンティング、オーバーウェルミングはいずれも物理攻撃に依存するため、物理攻撃 +8,000 の恩恵が非常に大きいです。さらに クラッシング +13,200 により、瀕死の敵を仕留める力も伸びます。予言のタリスマンは、瞬間火力よりもクリティカルの安定性や生存力を重視したい場合に選びましょう。

Alexandreのヒント: PvPで圧力をかけて素早くキルを取りたいなら、基本的には女戦士のタリスマンがおすすめです。物理攻撃 +8,000 と クラッシング +13,200 により、オーヤの主力スキルの実戦火力が伸び、フィニッシャー性能も高まります。予言のタリスマンに切り替えるのは、編成的に追加のヘルスやクリティカル率の安定感が欲しいときだけで十分です。

オーヤのレジェンダリーレリック スキルアップグレード優先度 - ヒーローウォーズ アライアンス

レリックはオーヤに強力なスケーリングと新しい効果をもたらし、このガイドは各スキルをやさしく説明しているので、最初に正しいスキルをアップグレードできます。

1番目 - シールドブレーカー

シールドブレーカーは、オーヤにとって最重要のダメージスキルです。最も近い敵に強烈な一撃を与え、そのダメージの30%をマークされた敵にも跳ね返します。さらに、シールドを持つ敵はオーヤの全スキルから追加で100%ダメージを受けるため、シールドに頼る編成に対して非常に強力です。ダメージは、予言のタリスマン装備時で 584,655 (物理攻撃の500% 116,451 + 2,400)、女戦士のタリスマン装備時で 614,655 (物理攻撃の500% 122,451 + 2,400) です。

予言のタリスマン使用時の公式

  • 公式 1: ダメージ: 584,655 (500% x 116,451 + 2,400)
  • 公式 2: マーク済み敵ダメージ: 175,396.5 (584,655 の30%)

女戦士のタリスマン使用時の公式

  • 公式 1: ダメージ: 614,655 (500% x 122,451 + 2,400)
  • 公式 2: マーク済み敵ダメージ: 184,396.5 (614,655 の30%)

スキルアニメーション情報

  • アニメーションディレイ: 0.78秒
  • レンジ: 100
  • キル時にエネルギー取得: 700

進化優先度: 非常に高いです - オーヤの直接火力と対シールド性能を同時に大きく伸ばせるため、最優先で強化したいスキルです。


1番目 - シールドブレーカー(強化スキル) レジェンダリーレリック: レベル 10

このレジェンダリー強化により、シールドブレーカーはさらに危険なスキルになります。元のスキルダメージの75%が、すべてのシールド状態の敵にも追加で入るため、単体処理だけでなく敵全体への圧力源としても機能します。追加ダメージは、予言のタリスマン装備時で 438,491.25 (584,655 の75%)、女戦士のタリスマン装備時で 460,991.25 (614,655 の75%) です。

予言のタリスマン使用時の公式

  • 公式 1: シールド敵への追加ダメージ: 438,491.25 (584,655 の75%)

女戦士のタリスマン使用時の公式

  • 公式 1: シールド敵への追加ダメージ: 460,991.25 (614,655 の75%)

進化優先度: 非常に高いです - このアップグレードは非常に価値があります。なぜなら、オーヤの最高のスキルの1つをはるかに強力なアンチシールド チームペナルティツールに変えるからです。

2番目 - ハンティング

ハンティングは、オーヤが戦闘をコントロールしながら味方を支援できる重要なスキルです。最もヘルスが低い敵をマークし、その対象を引き寄せ、さらにその敵への攻撃時にエネルギー燃焼を発生させます。また、オーヤから回復を受ける味方や自己回復した味方には、追加のクリティカルヒット確率を付与します。ボーナス値は、予言のタリスマン装備時で 9,333.825 (物理攻撃の7.5% 116,451 + 600)、女戦士のタリスマン装備時で 9,783.825 (物理攻撃の7.5% 122,451 + 600) です。ネイチャー英雄にはこの効果が2倍になり、18,667.65 と 19,567.65 になります。

予言のタリスマン使用時の公式

  • 公式 1: クリティカルヒット確率ボーナス: 9,333.825 (7.5% x 116,451 + 600)
  • 公式 2: ネイチャー英雄のクリティカルヒット確率ボーナス: 18,667.65 (15% x 116,451 + 1,200)

女戦士のタリスマン使用時の公式

  • 公式 1: クリティカルヒット確率ボーナス: 9,783.825 (7.5% x 122,451 + 600)
  • 公式 2: ネイチャー英雄のクリティカルヒット確率ボーナス: 19,567.65 (15% x 122,451 + 1,200)

スキルアニメーション情報

  • 初期クールダウン: 10秒
  • クールダウン: 25秒
  • キーワード: マーク、コントロール
  • アニメーションディレイ: 0.5秒
  • 期間: 5秒

進化優先度: 高いです - コントロール、エネルギー妨害、クリティカル編成との相性をまとめて強化できるため、多くのチームで実用価値が高いスキルです。

3番目 - 圧倒

圧倒はオーヤの素速い3ヒット スキルです。次のヒットはより強くなり、メインターゲットの後ろのシールド敵も、ダメージの一部を受けます。これは、ターゲットの終了と、シールドの後ろに隠れるチームへの圧力に役立ちます。ヒットごとの増加は予言のタリスマンで 38,712.75 (物理攻撃の25% 116,451 + 9,600) または女戦士のタリスマンで 40,212.75 (物理攻撃の25% 122,451 + 9,600) です。

予言のタリスマン使用時の公式

  • 公式 1: ヒットごとのダメージ増加: 38,712.75 (25% x 116,451 + 9,600)
  • 公式 2: ターゲットの後ろのシールド敵へのダメージ: 19,356.375 (38,712.75 の50%)

女戦士のタリスマン使用時の公式

  • 公式 1: ヒットごとのダメージ増加: 40,212.75 (25% x 122,451 + 9,600)
  • 公式 2: ターゲットの後ろのシールド敵へのダメージ: 20,106.375 (40,212.75 の50%)

スキルアニメーション情報

  • クールダウン: 15秒
  • アニメーションディレイ: 0.01秒
  • レンジ: 120
  • ヒット: 3

進化優先度: 中高 - 堅実な追加ダメージとシールド越しの圧力を与えられますが、ほとんどの戦闘ではシールドブレーカーやハンティングより優先度は一段下がります。


3番目 - 圧倒(強化スキル) レジェンダリーレリック: レベル 20

このアップグレードは強い間接的なコントロールを追加します。すべてのヒットはシールド敵全員から200エネルギーをバーンします。スキルは3回ヒットするため、シールド敵ごとに1回のスキル使用ごとに 合計600エネルギーがバーンされます。

スキルアニメーション情報

  • ヒット: 3
  • ヒットごとのエネルギー バーン: 200
  • 総エネルギー バーン: 600

進化優先度: 高いです - シールド持ちの敵全員のエネルギーを削れるため、相手のスキル回転を遅らせつつ、オーヤの対シールド性能をさらに高められます。

4番目 - 残忍な猛襲

残忍な猛襲はオーヤのパッシブスキルです。味方がクリティカルダメージを与えるか、敵のシールドを破壊すると、その味方はヘルスを回復します。つまり、チーム全体でクリティカル発生やシールド破壊が多いほど、継続回復も増えていきます。回復量は、予言のタリスマン装備時で 38,323.075 (ヘルスの2.5% 1,508,923 + 600)、女戦士のタリスマン装備時で 36,323.075 (ヘルスの2.5% 1,428,923 + 600) です。ネイチャー英雄は 76,646.15 と 72,646.15 を受け取ります。

予言のタリスマン使用時の公式

  • 公式 1: ヘルス回復: 38,323.075 (2.5% x 1,508,923 + 600)
  • 公式 2: ネイチャー英雄のヘルス回復: 76,646.15 (5% x 1,508,923 + 1,200)

女戦士のタリスマン使用時の公式

  • 公式 1: ヘルス回復: 36,323.075 (2.5% x 1,428,923 + 600)
  • 公式 2: ネイチャー英雄のヘルス回復: 72,646.15 (5% x 1,428,923 + 1,200)

スキルアニメーション情報

  • トリガー: 味方英雄がクリティカルダメージを与えるか、敵のシールドを破壊したとき

進化優先度: 中程度 - 回復性能は優秀ですが、火力やコントロールに直結する強化を優先した後で伸ばすのが理想です。

5番目 - プレデター バイト(新スキル) レジェンダリーレリック: レベル 1

プレデター バイトは、10秒ごとに発動して継続的な対シールド圧力を加える新しいレジェンダリースキルです。最も近い敵にオーヤの物理攻撃100%のダメージを与え、さらにシールドを持つすべての敵にオーヤの物理攻撃50%のダメージを与えます。予言のタリスマンでは主対象に116,451、各シールド敵に58,225.5です。戦乙女のタリスマンではそれぞれ122,451と61,225.5になります。

予言のタリスマンでの式

  • 式 1: 主対象へのダメージ: 116,451 (100% x 116,451)
  • 式 2: 各シールド敵へのダメージ: 58,225.5 (50% x 116,451)

戦乙女のタリスマンでの式

  • 式 1: 主対象へのダメージ: 122,451 (100% x 122,451)
  • 式 2: 各シールド敵へのダメージ: 61,225.5 (50% x 122,451)

スキル情報

  • 発動間隔: 10.0秒ごと
  • 主対象への倍率: 物理攻撃100%
  • シールド敵への倍率: 物理攻撃50%

進化優先度: 高いです - オーヤが狙いたい相手に自動で追加ダメージを与え続けられる強力な圧力手段であり、シールドを頻繁に張る編成に対してさらに価値が高まります。

6番目 - ハントレス フューリー(新スキル) レジェンダリーレリック: レベル 30

ハントレス フューリーは、敵にシールドが付与されるたびにオーヤの現在ダメージを20%、12.0秒間増加させるパッシブ型のレジェンダリースキルです。敵チーム全体にシールドが付与された場合、そのシールドを受けた各英雄ごとに1回ずつ発動するため、バリア主体の編成に対して特に危険な強化になります。

発動情報

  • ダメージ増加: 20%
  • 持続時間: 12.0秒
  • トリガー: 敵にシールドが付与されるたびに発動
  • 全体シールド時の挙動: シールドを受けた敵英雄ごとに1回発動

進化優先度: 非常に高いです - シールドが多い戦闘では反復型のダメージ増幅として機能するため、戦闘が長引くほどオーヤの伸びが大きくなり、防御側のシールド循環を非常に効率よく咎められます。

オーヤの最高のスキン ヒーローウォーズ アライアンス

ヒーローウォーズ アライアンスでオーヤのアップグレードに最適なスキンを見つけてください。これらは戦闘中のパフォーマンスとスキルの影響を改善し、新しいステラースキンも含まれています。

デフォルトスキン

ストレングス +1,365。ストレングスの各ポイントは、ストレングスがメインステップである場合、ヘルス+40と物理攻撃+1ボーナスを提供します。オーヤの最初の3つのスキルは物理攻撃でスケーリングし、4番目のスキルはヘルスでスケーリングするため、このスキンはすべてのスキルをブーストさせ、彼女にとって最も重要なスキンになります。

進化の優先度： 非常に高い – コアステップで、ダメージと耐久性の両方を最大化します。常に最初にアップグレードしてください。

ミシカルスキン

+7,095 物理攻撃。オーヤのメインオフェンシブスキン：シールドブレイカー、ハンティング、オーバーウェルミングのダメージをブーストします。これら3つのスキルは物理攻撃で直接スケーリングするため、このスキンはキットとの相性が非常に良いです。

オーヤと相性の良い味方は誰か?

味方 スキルシナジー

ヤスミン
ヤスミンは急所ダメージの確率が高いキャラクターです。オーヤの味方が急所ダメージを与えるたびに、オーヤのパッシブ効果から回復と一時的な急所ヒットボーナスを受け取ります。

チャッバ
チャッバは、前線の敵を食べて無効化できる耐久力のあるタンクです。これによりオーヤは邪魔されることなく攻撃でき、受ける圧力が減ります。彼の群衆制御と生存性により、オーヤはより長く活動を続けることができ、敵の盾を一貫して破壊することができます。

エルミル
エルミルは自分をクローンした後、後方に移動して安全な位置から遠距離ダメージを与えます。彼の武器アーティファクトはオーヤの装甲貫通力を高めます。ドリアンのいるチームでは、彼は追加の急所ダメージを得て、オーヤの急所ベースのヒーリングと完璧にシナジーします。

グース
グースは急所ヒット確率を高め、ゴールデンフェザーで味方を治癒します。オーヤはこれらのバフから多大な利益を得て、ブルータルオンスロートでより多くの急所ヒットと治癒効果をトリガーします。継続的な急所ビルドのトップシナジーです。

ジュー
ジューはヘルスが少ないほど莫大なダメージを与えます。オーヤの盾破壊とエネルギー消費効果は目標をより弱くするのに役立ち、ジューがより速くキルを確保するのを可能にします。両者とも急所ヒット中心の構成から利益を得ています。

イシュマエル
イシュマエルは急所が多いチームで繁栄します。オーヤのパッシブ急所ヒット確率ボーナスは、彼のバースト戦法をサポートします。より長い戦闘では、彼らの組み合わせた急所スケーリングは敵の前線を圧倒することができます。

オーヤは、盾を無視する能力と味方の急所ヒット可能性を高める能力により、戦闘で大きな違いをもたらすことができる強力で多目的なフロントラインヒーローです。彼女は物理的および急所ベースのチーム構成で優れており、特にグース、ヤスミン、イシュマエル、ジューのようなヒーローと組み合わせた場合に優れています。
